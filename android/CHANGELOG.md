# Novidades do Lumen PDF para Android

## 0.1.0

- Primeira versão: abra PDFs pelo app ou direto do WhatsApp, e-mail ou Arquivos ("Abrir com" / "Compartilhar").
- Leitura com rolagem contínua, pinça para zoom e toque duplo para ampliar.
- Busca no documento com destaque dos resultados, sumário (marcadores) e "Ir para a página".
- Links clicáveis, modo noturno, copiar o texto da página e compartilhar o PDF.
- Recentes com miniatura e a última página lida; PDFs com senha.
- Atualização automática: o app avisa quando sair uma versão nova.
